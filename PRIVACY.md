# ResearchBinder Privacy Policy

Last updated: June 10, 2026

ResearchBinder does not collect, sell, share, transmit, or store personal data outside your browser.

ResearchBinder runs locally in Chrome to collect tabs, selected text, and notes into research sessions that you can export as Markdown.

## Data Stored Locally

ResearchBinder stores sessions, captured tabs, selected-text snippets, notes, and settings in Chrome extension storage. This data stays in your browser unless you use browser sync features controlled by Chrome.

## Page Interaction

ResearchBinder reads selected text only when you explicitly use the context menu or keyboard shortcut to capture a snippet. Tab capture happens only when you request it.

## Data Collection

ResearchBinder does not use analytics, advertising SDKs, external tracking, remote logging, or external servers. It does not transmit sessions, snippets, tab URLs, page content, or settings to the developer or any third party.

## Permissions

ResearchBinder requests browser permissions only to provide local research capture features: storage for sessions, tabs/activeTab for user-requested tab capture, context menus for selected-text capture, clipboard write for Markdown export, and content-script access for selected-text capture.
